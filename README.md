# Product Management Super-Skill

A comprehensive, single-file AI-agent skill that merges **Perplexity Computer's 6 built-in PM skills** with **Claude Code's product team toolkit** into one unified reference for product management work.

## Features

- **PRD & Feature Specs** — 4 PRD formats, scope management, review cycles, acceptance-criteria patterns
- **Roadmap & Prioritization** — RICE, MoSCoW, ICE, Now/Next/Later, quarterly themes
- **Sprint & Agile** — 5 ceremony formats, velocity forecasting, sprint health scoring, Monte Carlo forecasting
- **Metrics & OKRs** — North Star metrics, L1/L2 hierarchy, dashboard principles
- **User Research & UX** — method selection, interview analysis, personas, journey mapping
- **UI Design Systems** — design tokens, atomic design, responsive breakpoints, WCAG guidance
- **Competitive Analysis** — feature matrices, win/loss methodology, monitoring
- **Stakeholder Comms** — 4 audience templates, ROAM risk register, ADR format
- **Persistent Planning** — three-file planning system (`task_plan.md`, `findings.md`, `progress.md`), 3-Strike Error Protocol
- **Cross-Skill Workflows** — end-to-end feature dev, quarterly planning, research sprints

## Quick Start

1. Open `SKILL.md` in this repo.
2. Upload it to your Perplexity Computer user settings, or drop it into your Claude Code skills directory.
3. Invoke it whenever you do PM work: PRDs, roadmap planning, sprint management, user research synthesis, stakeholder updates, or prioritization.
